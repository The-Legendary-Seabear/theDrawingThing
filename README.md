Snake Game

Description:
This project is just a simple snake game in c++ where you can move your snake with your arrow keys and when you eat the apple your snake will grow by one cell. The game will end when you collide with a wall or crash into yourself. This project uses the madlibs library.

How to install and run:
1. Download the zip file underneath the code section in github
2. extract the file
3. run the file with any software that can run C++ for example Visual Studio
4. Click the build and run button in your IDE or compile it manually to start playing.
